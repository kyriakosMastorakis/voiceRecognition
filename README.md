Text to Speech App (Python)

A simple Text-to-Speech (TTS) application built with Python and the pyttsx3 library.
The program allows users to enter text, choose a voice, and adjust the speaking speed.

Features
Convert text to speech
Adjustable speech speed
Multiple voice selection
Simple command-line interface
Offline speech synthesis
Requirements

Install the required library:# voiceRecognition
pip install pyttsx3
Run the Program
python main.py
How It Works
The program displays all available system voices
The user selects:
Speech speed
Voice index
Text to read
The application converts the text into speech and plays it aloud
Example 
available voices:
0 - Microsoft David Desktop
1 - Microsoft Zira Desktop

Give me speed(50 - 200): 150
choose number of voice: 1
enter your text: Hello World
Technologies Used
Python
pyttsx3
Description

This project demonstrates a basic Text-to-Speech system using Python.
It is a beginner-friendly application for learning speech synthesis, user input handling, and working with Python libraries.
The app works offline and supports multiple voices depending on the operating system.
